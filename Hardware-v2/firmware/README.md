# DigiRadio v2 firmware

Firmware for the second DigiRadio board ([`../kicad`](../kicad)).

The first board's firmware lives in [`../../Software`](../../Software). The v2
board replaces the ADAU1701 with an ADAU1452 DSP, so its audio driver and DSP
program differ; what else carries over from the v1 firmware is still to be
decided.

Status: not started.
